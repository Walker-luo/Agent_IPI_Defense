框架介绍：BaseIntent

可信任务先经 Authorization。规划器产生候选后，Precheck 校验整批，Audit 核对非免审动作。Monitor 介导执行，原生结果反馈给规划器和 Intent Progress。

Authorization · 可信任务工具授权
有效用户任务明确委托的文件先准备读取
两次调用生成目标与工具宿主归并准备前缀并分配固定 ID
冻结全局权限附带固定 ID 的进度关联
Precheck 校验每项工具的注册状态、权限、原生 schema 和风险元数据，发现无效候选即拒绝整批
Audit · 当前动作语义审计
当前候选动作工具、参数与有限动作历史
任务对齐审计外发同时核对正文与目的地

Precheck
非法候选使整批拒绝

执行前校验注册、任务授权、原生 schema 和元数据。授权保存在宿主侧，候选参数不能扩大权限。

Authorization
全局权限在任务内冻结

第一次调用分解目标及类型，宿主无损归并准备前缀并分配 ID；第二次选择全局工具并关联准备与完成足迹（prepare_tools / completion_groups）。进度关联不能授予或禁止工具。

Intent Progress
逐项推进目标

宿主管理状态并核对实际成功调用或消息；错误、阻挡和助手声称完成都不是执行证据。复杂目标仍需语义判断；未知条件不等于 false。自动完成仅限已审核的有界单次直接邀请场景。

Audit
按目标和约束判断

审计使用当前目标、完整任务约束、原生工具定义及有界证据；外发同时检查正文和目的地。判决严格为 allow、deny 或 abstain 及对应字段；无解析修补或默认放行。

Audit · 固定读取免审
所有路由模式生效

已注册、已授权且 schema 合法的 public/internal 读取免审；personal/secret 读取与效果调用仍审计。免审不筛选 URL、sink 或对象隐私；internal 工具可能读取私有频道。

Monitor · 执行
整批回执与一次性票据

混合批次只审计非免审部分，仍按原顺序介导整批。执行前复核权限、目录及意图状态，票据绑定调用与上下文并防止重放。

任务来源
仅展开明确委托

受支持的明确委托来源先经监控读取，再与原用户约束组成有效任务；普通返回不能扩权或递归委托。读取失败、歧义和超限时失败关闭，用户确认后受污染的任务文件不在支持范围。

配置与边界
路由 off 仍启用 Audit

网页/API 默认 off，CLI 默认 shadow；三种路由共享固定免审范围。工具级授权不保证对象或参数权限，最终纯文本没有独立动作审计；语义满足判断也不等于事实认证。
