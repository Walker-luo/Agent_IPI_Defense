# 当前框架与更新入口

当前引擎标识为 **BaseIntent**，默认 profile 选择器仍为 `legacy`。两次 Authorization 调用、宿主无损准备归并、固定 ID 键进度关联及 host-events 路由已实现；全局工具权限保持冻结，关联不变成每意图授权。

当前语义进度协议只允许 satisfaction/evidence_ids，宿主控制状态与顺序推进。有限直接邀请模式可由真实成功事件完成，复杂目标仍需语义判断。Audit 保持四字段有限判决与 public/internal 有效读取在所有模式固定免审的边界。

完整当前说明见[框架](framework.md)，运行默认值见[配置](model_tool_configuration.md)，命名及历史读取见[迁移](migration.md)。

## GrantBind 对照（2026-11-20）

此节记录 2026-11-20 按 GrantBind `05800a9` 的默认 `static-task-v354` 与当时 BaseIntent `legacy` 做的对照。

| 环节 | GrantBind | BaseIntent |
| --- | --- | --- |
| 意图解析 | 摘要引用宿主生成的可信原文片段，标注独立、依赖前一项或条件关系。引用校验可发现无效 ID 或位置，摘要覆盖和关系语义仍需验证。 | 输出目标类型，宿主先归并准备项再分配 ID。现有协议不能定位每项约束来自原文何处。 |
| 授权与绑定 | 用完整请求、辅助视图和紧凑原生目录编译冻结的全局权限。Monitor 绑定当前任务、授权、目录和实际调用，消费一次性票据。 | 同样冻结全局权限并校验整批。固定 ID 的工具关联用于进度，Monitor 还绑定当前意图状态。两者都需要 Audit 判断实际参数是否符合任务。 |
| 推进 | 静态任务视图辅助规划和审计，无宿主语义完成闸门。 | 执行证据归属到运行前的意图。宿主推进顺序，复杂情况以成功证据及实际答案支持有限语义判定。 |
| 审计 | 完整请求、带原文定位的辅助视图、原生参数 schema 和有界回执；读取免审还要求 `sink=none`。 | 完整请求和当前意图、原生 schema、动作及回执；已注册、已授权且参数有效的 public/internal 读取固定免审。 |

本次引入按需回执预算。较长证据包可在同一次 Audit 请求中保留更多上下文，便于核对正文尾部条件、候选动作依据及最新更正。此轮范围限于工具回执、历史调用参数和错误预览。详见[证据预算与审计边界](framework.md#audit)。更长的包会增加输入 Token 和可见的不可信文本，需单独测量误拒和对注入的敏感性。

下一步优先验证原文锚点。可将可信任务片段 ID 随 Authorization 输入生成，记录意图关联片段；归并准备项时保留双方引用，完整任务继续传递。以多条件、禁止项、代词和跨句依赖的标注样本比较遗漏率、错误关联率、进度错判和调用成本。关系标签先用于诊断，能够证明收益后再设计与宿主状态的联动。

最近固定键 12 例：TSR 8/12→7/12、原生 ASR 0/8→0/8、progress 61→43、计分 Token −14.8%。效用/一般安全验收仍为 partial，不能用调用下降替代质量结论。后续工作应先复核多 answer 阶段与提前澄清，再独立设计对照；本页不授权追加模型调用。
